§ 04 — How It Works
08/10
from raw export to self-knowledge in five steps
01
export
go to google takeout, select youtube, download the zip archive. one download, everything included.
02
upload
drop the zip into tubelens. jszip + papaparse + cheerio extract every csv and html file automatically.
03
enrich
route handlers call youtube data api v3 to enrich each channel and video with title, thumbnail, and category metadata.
04
analyze
claude haiku processes your patterns and writes insight records — binge clusters, topic drift, peak hours, subscription mismatch.
05
discover
next.js server components render your dashboard instantly — heatmap, top channels, kpi cards, ai insights panel.
Takeout .zip → Prisma/Neon → YouTube API v3 → Claude Haiku → Server Components
